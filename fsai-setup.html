📦 Required Packages & Modules

React Frontend Packages

Most packages like react, react-dom, react-scripts are auto-installed when you run npx create-react-app. Only axios needs to be installed separately.

react

core

Core UI library for building component-based interfaces. (Auto-installed by CRA)

axios

util

HTTP client for making API requests to the backend. (Install separately)

npx create-react-app frontend
cd frontend
npm install axios

Node.js / Express Backend Packages

express

core

Fast, minimalist web framework for Node.js.

mongoose

core

MongoDB ODM for data modeling.

cors

core

Enable Cross-Origin Resource Sharing.

body-parser

util

Parse incoming request bodies.

npm init -y
npm install express mongoose cors body-parser

Python / Flask / AI-ML Packages

flask

core

Lightweight Python web framework for APIs.

flask-cors

core

Handle CORS in Flask applications.

numpy

core

Numerical computing with arrays & matrices.

pandas

core

Data manipulation and analysis.

scikit-learn

core

Machine learning algorithms & utilities.

joblib

util

Save/load ML models efficiently.

requests

util

HTTP requests from Python.

matplotlib

util

Data visualization and plotting.

pip install flask flask-cors numpy pandas scikit-learn joblib requests matplotlib

Angular Packages

All Angular packages (@angular/core, @angular/router, @angular/forms, rxjs, typescript, zone.js) are auto-installed when you run ng new. Only @angular/cli needs to be installed globally first.

@angular/cli

core

CLI tool to create, build, and serve Angular apps. (Install globally)

npm install -g @angular/cli
ng new AngularAPP

🚀 APP1 – Complete Setup

1 Create the Root Folder

Open Command Prompt or PowerShell:

mkdir C:\Alexa-FSAI-Exam
cd C:\Alexa-FSAI-Exam
mkdir APP1
cd APP1
2 Setup Backend (Node.js + Express)
mkdir backend
cd backend
npm init -y
npm install express mongoose cors body-parser
cd ..
3 Setup Frontend (React)
npx create-react-app frontend
cd frontend
npm install axios
React app is ready at http://localhost:3000 — run with npm start.
cd ..
4 Setup AI Service (Flask + ML)
mkdir ai-service
cd ai-service
pip install flask flask-cors numpy pandas scikit-learn joblib requests
cd ..\..

🅰️ AngularAPP – Complete Setup

1 Install Angular CLI Globally
npm install -g @angular/cli
Verify installation: ng version — should show Angular CLI version.
2 Create Angular Application
cd C:\Alexa-FSAI-Exam
ng new AngularAPP
Select Yes for routing when prompted. This creates the full Angular project with routing module.
3 Run Angular App
cd AngularAPP
ng serve
All required packages are auto-installed by ng new. Angular app runs at http://localhost:4200.

▶️ Running the Applications

APP1 / APP2 – Backend

cd backend
node server.js

Runs on :5000 (APP1) / :5002 (APP2)

APP1 / APP2 – Frontend

cd frontend
npm start

Runs on :3000 (APP1) / :3001 (APP2)

APP1 / APP2 – AI Service

cd ai-service
python app.py

Runs on :5001 (APP1) / :5003 (APP2)

AngularAPP

cd AngularAPP
ng serve

Runs on :4200

Prerequisites: Make sure you have Node.js (v18+), Python (3.9+), npm, and MongoDB installed on your system before starting.
